# Atlantic Agentic Labs MCP server

Connects Cursor (and other clients that read Agent Plugins) to Atlantic's
public, read-only MCP server at `https://ask.atlanticagenticlabs.com/mcp`.

Tools: `search_docs`, `search_published_knowledge`, `list_pages`,
`read_page`. All are read-only. No account or sign-in is needed.

- Documentation: https://docs.atlanticagenticlabs.com/mcp/public/
- Privacy policy: https://www.atlanticagenticlabs.com/legal/privacy
- Support: solutions@atlanticagenticlabs.com

## Privacy

Questions sent to the server are recorded in redacted form, without
identifiers, and kept for 12 months. The server holds no tenant or
customer data. See the privacy policy above.
